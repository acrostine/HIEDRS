HIEDRS -- directed connectivity matrices

Source = row, Target = column. Diagonal = intra-node authored flows (same domain, on both ends, between two DIFFERENT capabilities -- no capability flows to itself). Only authored capability→capability FlowRelationship rows count -- never a derived rollup, trigger, composition, or actor association. See SPEC_static_connectivity_analytics.md section 1 for the full definition.

Internal vs external connectivity -- domains, compared to system average

Internal = intra-domain authored flows (both endpoints in this domain). External = cross-domain authored flows touching this domain (either direction). "vs avg" is this domain's count divided by the system-wide average across all domains -- 1.0× is exactly average, higher is more connected than typical.

System average internal (domain): 14.0 (min 2, max 32)  |  System average external (domain): 9.1 (min 0, max 26)

Internal vs external connectivity -- capabilities, compared to system average

Internal is always 0 at capability level -- no capability flows to itself in this model (see the diagonal note above). External = every authored flow this capability touches, in either direction. Shown for structural symmetry with the domain table and so the "vs avg" external ratio is directly comparable across levels. Includes isolated capabilities (external=0), which is why the system average is lower here than the median connected capability.
